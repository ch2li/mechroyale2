# buckeye v1.0 — Mech Royale bot

`mechfight/1` 协议的 Python bot，只用标准库。把这个文件夹放到 GitHub 仓库根目录（`Dockerfile` 在最顶层）即可提交。

## 文件

| 文件 | 作用 |
| --- | --- |
| `bot.py` | 主逻辑（入口） |
| `nav.py` | 地图建模：行走网格、视线判断、A* 寻路 |
| `mechfight.py` | 官方 kit 的 wrapper（未改动） |
| `Dockerfile` | 镜像定义 |

## v1.0 修改内容（相对 kit 的 `example_bot.py`）

示例 bot 只会朝毒圈中心直走、看到谁就打谁。v1.0 加了：

**地图与移动**
- 读取 `world.json` 和 `terrain.i16`，建 1 m 行走网格：建筑、体育场、陡坡都算墙，并按机甲半径外扩。
- 在 4 m 粗网格上跑 A*，分摊到多个 tick 计算，单次决策不会超时。
- 预先算好连通区域：到不了的地方不会被选为目标；目标确实走不到时，用跳跃加喷气翻墙过去。
- 卡住检测：要求移动却几乎没动时，就跳、喷气，然后重新规划路线。

**毒圈**
- 计算收缩中的圈多久会扫到当前位置：时间够就先搜刮，不够就直接进圈（必要时加速）。
- 不站圈中心，而是在下一个圈内找一个背靠墙的点，面朝开阔方向警戒。

**搜刮**
- 武器优先级：激光 > 闪电 > 迫击炮。走到更好的武器旁边会捡起来（`take` 加 `drop` 换掉旧的）。
- 前期捡能量块、打箱子和 NPC 无人机，屋顶上的东西不去拿。
- 能及时赶到、且没人在占领时，去抢空投。
- 升级优先级：armor > plating > nanites > 激光升级 > 枪升级 > …

**战斗**
- 枪按子弹飞行时间算提前量；激光直接瞄准目标，充满且对准才松手；目标在锥形范围内自动放闪电；迫击炮用弹道解（没有视线时用高抛）。
- 视线检查：不会朝墙里开火。
- 躯干始终朝向目标（正面装甲；背后中弹伤害 ×1.5），腿部随机横移躲子弹。
- 交战距离按武器组合调整：有闪电时约 25 m（会加速贴近），有激光时 90 m，只有枪时 60 m。
- 被围攻或打不过时，退到掩体后回血；敌人血量和自己差不多或更低时绝不撤退。
- 躲避正对自己蓄力的激光（横移），以及迫击炮弹的预测落点。
- 被看不见的敌人打中、或听到枪声和脚步声时，转身朝那个方向看。

## 测试

```sh
python3 check/check.py -- python3 -u bot.py
docker build -t buckeye .
python3 check/check.py --map-dir /arena -- docker run --rm -i --network none --cpus 1 --memory 512m --read-only --tmpfs /tmp:rw,size=64m --user 65534:65534 -v "$PWD/arena:/arena:ro" buckeye
```

本地 `check.py` 结果：PASS，300 次中 0 次超时，最慢一次决策约 11–16 ms，内存约 25 MB。
